# Question bank tools

`data/questions.js` (360 questions) is generated by these files:

| File | What it holds |
|---|---|
| `seed_questions.json` | the team's original seed questions (60), in JSON |
| `convert_questions.py` | applies the reviewed fixes to the seed questions, merges the two files below, shuffles where each correct answer sits (fixed random seed, so the output is always the same) and writes `data/questions.js` |
| `new_questions.py` | 120 more questions (ids e04 to e10, m05 to m10, h04 to h10 per level) |
| `new_questions_b2.py` | 180 more questions (ids e11 to e20, m11 to m20, h11 to h20 per level) |

In the two question files, each question is written with its **correct answer first**; the converter moves it to a random position.

To regenerate, from the repository folder:

```
python3 tools/convert_questions.py tools/seed_questions.json data/questions.js
```

The result matches the committed `data/questions.js` byte for byte. Open `tests.html` afterwards to check the bank.
